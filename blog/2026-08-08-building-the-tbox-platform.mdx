The TBOX is the central control unit of our automation and monitoring ecosystem.

But the goal was never to create just another controller.

<!-- truncate -->

From the beginning, the idea has been to combine the functions that are commonly spread across several individual devices into one central platform.

The TBOX handles automation, monitoring and communication while additional devices extend the system where required.

That includes products for sensor inputs, pumps, valves and user interfaces.

One of our main priorities during development is keeping the system flexible without making configuration unnecessarily complicated.

This means a lot of time goes into things users hopefully never have to think about:

- Communication between devices
- Configuration and commissioning
- Firmware updates
- Error handling
- Network connectivity
- Hardware protection
- Diagnostics

There is still plenty to do, but the platform is gradually reaching the point where the individual pieces start feeling like one system rather than separate prototypes.
