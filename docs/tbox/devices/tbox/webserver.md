## Overview

The TBOX includes an integrated web server for configuration, diagnostics and firmware updates.

The interface is accessible from any modern web browser and requires no additional software.

## First Start

On the first startup, the TBOX automatically creates its own Wi-Fi Access Point for commissioning.

| Parameter | Value |
|-----------|-------|
| SSID | `TF_<MAC-Address>` |
| Password | `theskyisthelimit` |
| Default IP | `192.168.4.1` |

After connecting, open the following address in your browser:

```
http://192.168.4.1
```

Once the Wi-Fi credentials have been configured, the TBOX becomes accessible through your local network.

Supported methods:

- Upload firmware file
- Firmware URL

The device restarts automatically after a successful update.
